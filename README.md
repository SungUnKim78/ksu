# 정금농원 토마토 주문 페이지 (베타)

상자에 동봉한 QR을 찍으면 열리는 토마토 재주문 페이지입니다.

## 기능

**손님**
- `/` 주문 페이지: 3kg·5kg 수량 선택, 배송지 입력, 무료배송, 무통장 입금
- `/my/<토큰>` 주문 완료·주문 내역: 입금 안내, 발송 상태, 송장번호, 재주문 링크
- `/r/<토큰>` 재주문: 지난 배송지와 수량이 채워진 주문 페이지
- 같은 휴대폰으로 QR을 다시 찍으면 재주문 화면으로 바로 이어집니다
- 카카오 로그인 (설정한 경우에만 버튼 표시)

**관리자** (`/admin`)
- 주문 목록: 입금 확인 → 발송 완료(택배사·송장번호) → 취소, 30초마다 자동 새로고침
- 누적 주문·재주문 고객 비율·유입 경로 통계, 엑셀(CSV) 내려받기
- 가격·입금 계좌·판매 중지·공지 설정
- 동봉용 QR 만들기 (발송 구분 코드별), 인쇄

## 실행

```bash
cp .env.example .env.local   # 값 채우기
npm install
npm run dev                  # http://localhost:3000
```

PostgreSQL이 필요합니다. 표는 첫 접속 때 자동으로 만들어집니다.

## 배포 (Vercel 기준)

1. Vercel에서 이 저장소를 가져옵니다.
2. Storage에서 Postgres(Neon 등)를 연결하면 `DATABASE_URL`이 자동 등록됩니다.
3. 환경변수 `ADMIN_PASSWORD`, `SESSION_SECRET`을 등록합니다.
4. 배포 후 `/admin` → "가격·계좌 설정"에서 가격과 입금 계좌를 입력합니다.
5. `/admin/qr`에서 QR을 만들어 인쇄합니다.

## 카카오 로그인 (선택)

1. [카카오 개발자 콘솔](https://developers.kakao.com)에서 앱을 만들고 카카오 로그인을 켭니다.
2. Redirect URI에 `https://내도메인/auth/kakao/callback`을 등록합니다.
3. 환경변수 `KAKAO_REST_API_KEY`(필요 시 `KAKAO_CLIENT_SECRET`)를 등록합니다.

카카오에서는 회원번호만 받아 손님 정보와 연결하며, 추가 동의 항목은 필요 없습니다.
